# Fixed-structure tree leaf products

This lane checks continuous derivatives of a fitted tree ensemble's raw
margin with respect to its packed `[base_score, leaf weights]` coordinates.
The four-row fixture uses one depth-one split on feature one, targets
`[0,0,10,10]`, unit shrinkage, and `l2=1`. An independent NumPy stump oracle
expects the forward product `[1.5,1.5,2.5,2.5]` for tangent
`[0.5,1,2]`, and the reverse product `[10,3,7]` for output cotangent
`[1,2,3,4]`. Both XGBoost-style and LightGBM-style models agree exactly.

The products hold split routing, categorical partitions, DART/GOSS choices,
and tree scales fixed. Input derivatives therefore retain their split-boundary
refusal, while leaf-coordinate products remain defined on split surfaces.
CUDA is recorded as an unavailable capability row because no resident tree
model/derivative kernel is linked; no host fallback is counted.

| workload | phase | device | result |
| --- | --- | --- | --- |
| XGBoost tree leaf products | JVP/VJP | CPU | maximum NumPy error `0.0` |
| LightGBM tree leaf products | JVP/VJP | CPU | maximum NumPy error `0.0` |
| Both tree derivative APIs | capability check | CUDA | typed unavailable row |

The raw records are in [`tree_leaf_products.csv`](tree_leaf_products.csv),
generated by [`scripts/bench_tree_leaf_products.py`](../scripts/bench_tree_leaf_products.py).
Reproduce with:

```bash
python3 -B scripts/bench_tree_leaf_products.py \
  --fortml ../fortml --output results/tree_leaf_products.csv
```
