# XGBoost interaction constraints

The raw record is [`xgboost_interaction.csv`](xgboost_interaction.csv),
generated by [`scripts/bench_xgboost_interaction.py`](../scripts/bench_xgboost_interaction.py).
The release executable is `fortml_bench_xgboost_interaction`, rebuilt with
`fo build --flag -O3` before the run.

The fixture has 192 rows and three features. One depth-two tree is fitted so
that the unconstrained reference reaches seven nodes and the independent
group-mean oracle is exact. The constrained model assigns features one and two
to separate interaction groups, so a path that splits on one cannot split on
the other. The NumPy harness reconstructs the fixture and checks the complete
prediction vector, node counts, and reported fit diagnostics. CPU rows pass
with zero independent-oracle error.

CUDA is represented by an `unavailable` capability row. No resident CUDA
XGBoost tree kernel is linked in this release; the device contract therefore
reports a typed refusal rather than relabeling host execution as a GPU timing.

Run:

```bash
.venv/bin/python -B scripts/bench_xgboost_interaction.py \
  --fortml ../fortml --output results/xgboost_interaction.csv
```
