# Classifier-chain logistic workload

The raw record is [`classifier_chain.csv`](classifier_chain.csv), generated by
[`scripts/bench_classifier_chain.py`](../scripts/bench_classifier_chain.py).
The release executable is `fortml_bench_classifier_chain`.

The fixture has 192 rows, four continuous features, and three binary outputs.
FortML trains one logistic head per output using the observed positive
indicators from preceding columns. The release app writes the packed fitted
heads, probabilities, and integer predictions. The benchmark independently
replays those heads with NumPy sigmoids and thresholding before retaining fit
or prediction timings; the recorded maximum probability error is therefore a
forward-oracle check, not a comparison against the same Fortran output.

The CUDA row is `unavailable`: the classifier-chain device entry point returns
`FORTNUM_NOT_IMPLEMENTED` until a resident multi-head kernel is linked.

Run from this repository:

```bash
python -B scripts/bench_classifier_chain.py \
  --fortml ../fortml --output results/classifier_chain.csv
```
