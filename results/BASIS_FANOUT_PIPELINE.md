# Named basis fan-out/fan-in benchmark

The raw record is [`basis_fanout_pipeline.csv`](basis_fanout_pipeline.csv),
generated by [`scripts/bench_basis_fanout_pipeline.py`](../scripts/bench_basis_fanout_pipeline.py).
The harness first evaluates an independent NumPy fixture for the six-feature
quadratic branch and four-feature spectral branch, then runs
`test_basis_fanout_pipeline` with `fo test`. That Fortran test independently
checks the concatenated values, stable branch metadata, JVP/VJP contraction,
central-difference HVP, CPU dispatch, and CUDA refusal.

The CPU row records the complete correctness-gate wall time rather than a
synthetic per-element throughput claim. The CUDA row is intentionally
`unavailable`: no resident branch executor is linked, and the API returns
`FORTNUM_NOT_IMPLEMENTED` without a host fallback. Every row records source
and benchmark revisions.

Run from this repository with:

```bash
python3 -B scripts/bench_basis_fanout_pipeline.py \
  --fortml ../fortml --output results/basis_fanout_pipeline.csv
```
