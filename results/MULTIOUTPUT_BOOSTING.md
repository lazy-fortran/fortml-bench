# Multi-output XGBoost/LightGBM release lane

The raw record is [`xgboost_multioutput.csv`](xgboost_multioutput.csv),
generated by [`scripts/bench_xgboost_multioutput.py`](../scripts/bench_xgboost_multioutput.py)
against the release app `fortml_bench_xgboost_multioutput`.

The fixture has four samples, one feature, two targets, one tree, unit
learning rate, and unit L2 leaf regularization. The independent NumPy oracle
computes the mean base margin and the two closed-form stump corrections
directly. It checks prediction and staged-margin matrices, concatenated
fixed-leaf JVP/VJP vectors, metadata, and typed CUDA refusals. All CPU rows in
the current record have zero maximum absolute error. The VJP products are
also checked by the scalar adjoint contraction in the FortML behavioral test.

The app exercises malformed-fit transactionality and selected CUDA dispatch.
CUDA rows are recorded as `unavailable` with `FORTNUM_NOT_IMPLEMENTED`; no host
fallback is included in a device timing. Resident multi-output tree/histogram
kernels, distributed output sharding, and differentiable split topology remain
open work.

Reproduce with:

```bash
python3 -B scripts/bench_xgboost_multioutput.py \
  --fortml ../fortml --output results/xgboost_multioutput.csv
```
