# Multiclass SAMME AdaBoost

The raw record is [`adaboost_samme.csv`](adaboost_samme.csv), generated by
[`scripts/bench_adaboost_samme.py`](../scripts/bench_adaboost_samme.py). The
release executable is `fortml_bench_adaboost_samme`, rebuilt with
`fo build --flag -O3` before the run.

The fixture has nine one-feature rows, three sorted integer classes
`[-7, 4, 99]`, and five query points. The independent NumPy oracle replays
the deterministic depth-one CART tie at threshold `2.5`; its weighted error is
`1/3`, so the SAMME stage weight is
`log((1-1/3)/(1/3))+log(3-1)=log(4)`. It reconstructs the weighted-vote
margins, stabilized softmax probabilities, and labels. CPU rows are retained
only when every value matches the oracle; CUDA is an explicit unavailable row
because no resident multiclass AdaBoost tree kernel is linked.

Run:

```bash
python3 -B scripts/bench_adaboost_samme.py \
  --fortml ../fortml --output results/adaboost_samme.csv
```
