# Column basis pipeline device contract

The raw record is [`column_pipeline_device.csv`](column_pipeline_device.csv),
generated by
[`scripts/bench_column_pipeline_device.py`](../scripts/bench_column_pipeline_device.py).
The release app is `fortml_bench_column_pipeline_device`, rebuilt with
`fo build --flag -O3` before the run.

The fixture contains 2,048 rows and three input columns. A named Fourier stage
consumes column 3 and a polynomial stage consumes column 1; the four output
features are checked against independent NumPy `sin`, `cos`, `x`, and `x**2`
expressions. The CPU row is retained only when the complete feature matrix is
within the release tolerance. CUDA is an explicit unavailable row because no
resident basis executor is linked; the release app also checks that the typed
refusal leaves its output sentinel untouched.

Run:

```bash
python3 -B scripts/bench_column_pipeline_device.py \
  --fortml ../fortml --output results/column_pipeline_device.csv
```
