# Multiclass SAMME.R AdaBoost

The raw record is [`adaboost_samme_r.csv`](adaboost_samme_r.csv), generated by
[`scripts/bench_adaboost_samme_r.py`](../scripts/bench_adaboost_samme_r.py).
The release executable is `fortml_bench_adaboost_samme_r`, rebuilt with
`fo build --flag "-O3"` before the run.

The fixture has nine one-feature rows, sorted integer classes `[-7, 4, 99]`,
and five query points. The independent NumPy oracle reconstructs the
depth-one CART leaves `[1,0,0]` and `[0,1/2,1/2]`, clips zero probabilities at
`1e-12`, and checks the centred log-probability update, unit stage weight,
normalized geometric probabilities, and labels. CPU rows are retained only
when every value matches; CUDA is an explicit unavailable row because no
resident AdaBoost tree kernel is linked.

Run:

```bash
python3 -B scripts/bench_adaboost_samme_r.py \
  --fortml ../fortml --output results/adaboost_samme_r.csv
```
