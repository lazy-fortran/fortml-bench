# Binary AdaBoost classifier

The raw record is [`adaboost_classifier.csv`](adaboost_classifier.csv),
generated by [`scripts/bench_adaboost_classifier.py`](../scripts/bench_adaboost_classifier.py).
The release executable is `fortml_bench_adaboost_classifier`, rebuilt with
`fo build --flag -O3` before the run.

The fixture repeats a six-row one-feature classification problem. The first
depth-one CART weak learner has threshold `1.5`, weighted error `1/6`, and
AdaBoost weight `0.5*log(5)`. NumPy reconstructs the signed margin, logistic
probabilities, and integer labels independently. CPU rows are retained only
when the complete probability vector and labels match. CUDA is an explicit
unavailable capability row because no resident AdaBoost tree kernel is linked.

Run:

```bash
python3 -B scripts/bench_adaboost_classifier.py \
  --fortml ../fortml --output results/adaboost_classifier.csv
```
