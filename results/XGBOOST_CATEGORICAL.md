# Bounded categorical XGBoost

The raw record is [`xgboost_categorical.csv`](xgboost_categorical.csv),
generated by [`scripts/bench_xgboost_categorical.py`](../scripts/bench_xgboost_categorical.py).
The release executable is `fortml_bench_xgboost_categorical`, rebuilt with
`fo build --flag -O3` before a release run.

The fixture has 256 rows, one integer-coded feature with four equally sized
categories, and one numeric nuisance feature.  The target is zero for codes
0 and 1 and four for codes 2 and 3.  A single depth-one ordered-gradient tree
therefore has an independent three-node partition oracle.  The harness checks
the complete prediction vector and the reported fit diagnostic against this
NumPy oracle, then records repeated fixed-tree prediction timing.  The CPU
rows use FortML revision `c8ee155`; the observed independent-oracle error is
zero.  The CUDA row is intentionally `unavailable`: no resident CUDA
categorical-tree kernel is linked, so the device contract is a typed refusal.

Run:

```bash
.venv/bin/python -B scripts/bench_xgboost_categorical.py \
  --fortml ../fortml --output results/xgboost_categorical.csv
```
