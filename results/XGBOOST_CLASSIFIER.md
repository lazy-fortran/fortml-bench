# Binary XGBoost classifier facade

Run date: 2026-08-07.  The raw release record is
[`xgboost_classifier.csv`](xgboost_classifier.csv), generated by
[`scripts/bench_xgboost_classifier.py`](../scripts/bench_xgboost_classifier.py)
from the `fortml_bench_xgboost_classifier` application.

The fixed workload has 192 samples, three features, twelve depth-two trees,
positive deterministic sample weights, and arbitrary integer classes `[-5,17]`.
The Python side independently checks sorted class ordering and the probability
simplex contract.  The release app checks that the final staged probability
slice equals `predict_proba`, that integer `predict` is deterministic, and
that normalized gain importance sums to one.

| phase | backend/device | seconds/op | checked value |
| --- | --- | ---: | ---: |
| contract oracle | NumPy/CPU | 0 | simplex max error 0 |
| fit | FortML/CPU | 1.028463e-3 | log loss 4.9245768172846593e-2; accuracy 0.984375 |
| predict | FortML/CPU | 8.34353125e-6 | accuracy 0.984375; gain sum 1 |
| predict | FortML/CUDA | unavailable | typed `FORTNUM_NOT_IMPLEMENTED` |

The CPU rows are release timings only and are not GPU evidence.  CUDA remains
an explicit unavailable row because no resident tree/histogram kernel is
linked.  The CSV records source and benchmark revisions, compiler, flags,
Python, and NumPy versions for reproducibility.

Reproduce with:

```bash
python3 -B scripts/bench_xgboost_classifier.py \
  --fortml ../fortml --output results/xgboost_classifier.csv
```
