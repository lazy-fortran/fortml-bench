# XGBoost query derivative products

The raw record is [`xgboost_derivatives.csv`](xgboost_derivatives.csv),
generated by [`scripts/bench_xgboost_derivatives.py`](../scripts/bench_xgboost_derivatives.py).
The release executable is `fortml_bench_xgboost_derivatives`; it is rebuilt
with `fo build --flag -O3` before each run.

The fixture fits one exact depth-one squared-loss tree to eight ordered samples.
Six query points lie strictly away from the learned threshold.  The harness
recomputes the central-difference JVP from the emitted `x ± 10^-6` prediction
vectors and independently checks the reverse-mode directional product.  Since
the fitted tree is piecewise constant, both products must be zero.  The CSV
retains CPU timings only after these checks pass.

Two additional rows exercise the derivative contract on the learned split
surface: both JVP and VJP must return `FORTNUM_DOMAIN_ERROR`.  The CUDA row is
an explicit `FORTNUM_NOT_IMPLEMENTED` capability refusal; no host prediction is
counted as GPU work while resident tree kernels are absent.

Run:

```bash
.venv/bin/python -B scripts/bench_xgboost_derivatives.py \
  --fortml ../fortml --output results/xgboost_derivatives.csv
```
