# Shared trainer and tree-contribution correctness gates

Run date: 2026-08-07. The raw record is
[`training_core.csv`](training_core.csv), generated by
[`scripts/bench_training_core.py`](../scripts/bench_training_core.py).

This report records correctness gates for the model-agnostic `fortml_trainer`
objective state machine and the XGBoost additive tree-contribution API. The
Fortran tests own the behavioral checks; the harness independently reconstructs
the trainer's first weighted quadratic SGD update with NumPy. The recorded
seconds are gate wall times and are not model-throughput measurements.

The trainer row covers explicit optimizer state, clipping/EMA bookkeeping,
clone/resume state, bounded L-BFGS-B, and malformed bounds. The XGBoost row
covers regression and logistic additive raw-margin reconstruction, staged
equivalence, shape refusals, and typed CUDA refusal.

Reproduce:

```bash
python3 scripts/bench_training_core.py \
    --fortml ../fortml --output results/training_core.csv
```

No PyTorch/JAX performance claim is inferred from these correctness rows.
