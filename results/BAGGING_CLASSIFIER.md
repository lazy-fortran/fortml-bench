# Bagging classifier

The raw record is [`bagging_classifier.csv`](bagging_classifier.csv),
generated by [`scripts/bench_bagging_classifier.py`](../scripts/bench_bagging_classifier.py).
The release executable is `fortml_bench_bagging_classifier`, rebuilt with
`fo build --flag -O3` before the run.

The workload contains 240 rows, three numeric features, three integer classes,
and six cluster queries. FortML fits 32 seeded bootstrap CART trees with a
180-row subset and checks both the probability simplex and independently
computed cluster labels. CPU rows are retained only when all six labels agree
and the simplex error is below the release tolerance. CUDA is an explicit
unavailable row because no resident bagging ensemble kernel is linked.

Run:

```bash
python3 -B scripts/bench_bagging_classifier.py \
  --fortml ../fortml --output results/bagging_classifier.csv
```
