# LightGBM GOSS

This correctness-gated lane exercises FortML's bounded LightGBM gradient-based
one-side sampling (`boosting_type="goss"`). The independent NumPy oracle
replays the four-row one-dimensional Newton tree with `top_rate=0.5`,
`other_rate=0.25`, and seed `1729`: the largest-gradient rows are retained,
one deterministic hash-ranked remainder row is retained with the exact
`(1-a)/b = 2` gradient/Hessian correction, and exhaustive split evaluation
produces predictions `[0, 0, 10, 10]`.

The release app also checks exact seed replay, malformed-rate refusal, fitted
rate/type metadata, fit/predict timings, and the selected-CUDA typed refusal.
The raw report is [`lightgbm_goss.csv`](lightgbm_goss.csv), generated by
[`scripts/bench_lightgbm_goss.py`](../scripts/bench_lightgbm_goss.py).

| phase | backend/device | checked result |
| --- | --- | --- |
| oracle | NumPy/CPU | prediction max error 0 |
| fit | FortML/CPU | 1.60e-5 s |
| predict | FortML/CPU | 1.00e-6 s; NumPy max error 0 |
| seed replay | FortML/CPU | max error 0 |
| invalid rates | FortML/CPU | `FORTNUM_DOMAIN_ERROR` (1) |
| predict | FortML/CUDA | `FORTNUM_NOT_IMPLEMENTED` (3) |

Reproduce with:

```bash
python3 -B scripts/bench_lightgbm_goss.py \
  --fortml ../fortml --output results/lightgbm_goss.csv
```
